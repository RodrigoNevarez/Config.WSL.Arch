#+TITLE: rnevarez-arch-config
#+AUTHOR: Rodrigo Nevarez
#+OPTIONS: toc:nil num:nil

Personal configuration and knowledge-base repository for an Arch Linux
environment running under WSL. It tracks the environment's installed
dependencies, ongoing setup/configuration work as Org-mode TODOs, and a
small Emacs Org-mode wiki with guides used by an AI coding agent (AGY)
to maintain that wiki.

* Repository Layout

| Path                    | Purpose                                                              |
|--------------------------+-----------------------------------------------------------------------|
| =config/=                 | Tracked dotfiles (=.bashrc=, =.bash_profile=, =.gitconfig=, =init.el=) deployed onto the environment. |
| =scripts/=                | Maintenance/deployment scripts: =install-config.sh= deploys =config/= into =$HOME=, =install-packages.sh= installs the packages from =docs/ENVIRONMENT.org=. |
| =docs/ENVIRONMENT.org=    | Snapshot report of installed pacman packages, dev tools, and Node/NVM versions. |
| =docs/TODO/=              | Active Org-mode TODO files tracking in-progress environment setup tasks. |
| =docs/TODO/done/=         | Completed TODO files, kept for history/reference.                    |
| =.agents/wikis/00-GUIDES/= | Guides for creating and maintaining the Org-mode wiki (index structure, UUID linking, detail-page generation). |

* Config Files

[[file:config/][config/]] holds the actual dotfiles tracked by this repo, mirroring
their =$HOME= layout: =.bashrc=, =.bash_profile=, and =.gitconfig= for
the shell, and =.emacs.d/init.el= for Emacs.
[[file:scripts/install-config.sh][scripts/install-config.sh]] copies
every file under =config/= to the matching path under =$HOME=,
backing up any existing file that differs before overwriting it. Run
with =--dry-run= to preview changes without writing anything.

* Environment

This config targets an Arch Linux install running inside WSL. See
[[file:docs/ENVIRONMENT.org][docs/ENVIRONMENT.org]] for the current list of installed system
packages (pacman), development tools, and Node.js/NVM setup.
[[file:scripts/install-packages.sh][scripts/install-packages.sh]]
installs everything documented there: the pacman packages, =nvm= and
the pinned Node.js version, and the global npm packages. It also
prints a reminder that =antigravity= requires a manual install.

* TODOs

Setup and configuration work is tracked as individual Org-mode files
under [[file:docs/TODO/][docs/TODO/]], each named with a UUID and using standard Org
=TODO=/=DONE= checklist syntax. Completed items are moved to
[[file:docs/TODO/done/][docs/TODO/done/]].

* Wiki Guides

[[file:.agents/wikis/00-GUIDES/01-starters-guide.org][01-starters-guide.org]] and
[[file:.agents/wikis/00-GUIDES/02-detail-pages.org][02-detail-pages.org]] define the conventions for this repository's
Org-mode wiki: hierarchical index structure, mandatory UUID
=:PROPERTIES:= drawers for linkable nodes, and the workflow for
expanding a wiki node into its own detail page.

* Notes

- Files are kept in Org-mode (converted from Markdown) to support
  Emacs Org features such as =TODO= states, properties drawers, and
  UUID-based linking.
- Emacs =~= backup files and a =history/= directory are ignored (see
  =.gitignore=).
