#+TITLE: Give Arch bash an Ubuntu-like CLI theme
#+DATE: 2026-08-12

* Problem

Arch's default =/etc/bash.bashrc= / =~/.bashrc= ships a bare prompt and
no color defaults, unlike Ubuntu's which colorizes the prompt, =ls=,
and =grep= out of the box. Want the Arch WSL shell to feel similar.

* TODO Port Ubuntu-style bash theming [4/4]

- [X] Colorized, Ubuntu-style =PS1= (user@host in green, cwd in blue):
  #+begin_src sh
  PS1='\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
  #+end_src
  (Ubuntu's actual default also conditionally adds =debian_chroot= and
  switches to red for root — decide whether to keep that or simplify.)

- [X] Enable color support for =ls= / =dircolors=:
  #+begin_src sh
  if [ -x /usr/bin/dircolors ]; then
      test -r ~/.dircolors && eval "$(dircolors -b ~/.dircolors)" || eval "$(dircolors -b)"
      alias ls='ls --color=auto'
      alias grep='grep --color=auto'
      alias fgrep='fgrep --color=auto'
      alias egrep='egrep --color=auto'
  fi
  #+end_src

- [X] Ubuntu-style handy aliases (optional, check what's actually
  useful before copying wholesale):
  #+begin_src sh
  alias ll='ls -alF'
  alias la='ls -A'
  alias l='ls -CF'
  #+end_src

- [X] Reload and verify:
  #+begin_src sh
  source ~/.bashrc
  #+end_src
  Confirm prompt colors and =ls=/=grep= coloring show up as expected.
